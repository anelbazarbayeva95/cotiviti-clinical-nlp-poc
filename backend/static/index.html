Clinical Note Structuring POC

OCR + Claude extraction pipeline, built for the Cotiviti GenAI Research Engineer Intern assessment (Topic 1: Clinical NLP/LLM).

All notes on this page are synthetic and fictional, generated for demo purposes only. No real patient data (PHI) is used anywhere in this project.

Stage 1 — OCR

Simulates a scanned/faxed clinical note arriving with no structure at all — the historical starting point for clinical NLP.

Stage 2 — LLM Structuring

Claude reads the raw note text (from OCR above, or pasted directly) and returns structured fields via a forced tool call — no regex, no hand-built NER pipeline.
